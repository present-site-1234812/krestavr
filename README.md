# КРЕСТАВР

Адаптивный сайт-визитка строительной компании на HTML, CSS и JavaScript без сборки и зависимостей.

Стили и JavaScript встроены в `dist/index.html`: файл можно открывать отдельно, без соседних CSS/JS-файлов. Исходники сохранены в `dist/style.css`, `dist/script.js` и `dist/construction.js` (анимация строительства) и `dist/loader.js` (ранний экран загрузки). `dist/text-build.js` отвечает за декоративное появление текста с маленькими строителями.

Откройте `dist/index.html` в браузере или запустите из этой папки:

```sh
python3 -m http.server 8080 --directory dist
```

Затем откройте http://localhost:8080.

Работают мобильная навигация, фильтрация проектов, раскрывающиеся услуги, диалоги проектов и подготовка заявки для копирования. Форма не отправляет данные на сервер.

Название и проекты демонстрационные. Перед запуском замените их на материалы компании, добавьте настоящие контакты и при необходимости подключите обработчик заявок. Изображения сгенерированы встроенным ImageGen. Оригиналы сохранены в dist/assets, а в HTML встроены их копии в формате data URI. Для открытия сайта достаточно одного dist/index.html. Шрифт Golos Text встроен в CSS/HTML, внешних обращений к Google Fonts нет. Лицензия SIL OFL сохранена в dist/assets/fonts/OFL.txt и внутри HTML. Резервный шрифт — Arial.

Вдохновение: масштабная подача проектов и лаконичный язык американских строительных компаний, включая https://www.dpr.com/. Дизайн и код созданы для этого проекта.

Проверены синтаксис JavaScript, HTML/ARIA, синхронизация встроенных исходников и пользовательские сценарии в Playwright/Chromium. Выполнена визуальная проверка desktop, tablet и mobile; подробности — в DESIGN-AUDIT.md. Сайт опубликован: https://present-site-1234812.github.io/krestavr/. Репозиторий: https://github.com/present-site-1234812/krestavr. Последующие обновления публикуются через .github/workflows/pages.yml. Инструкция и скрипт запуска — в PUBLISHING.md.

## Редактирование

После изменения `dist/style.css`, `dist/script.js`, `dist/construction.js` `dist/text-build.js` или `dist/loader.js` выполните `python3 scripts/sync-inline.py`. Скрипт обновляет встроенные стили и логику в HTML, не затрагивая изображения. Это сохраняет открытие сайта одним файлом.

## Обновление дизайна

Первый экран разделён на текст и архитектурный кадр. Услуги представлены компактным списком с раскрытием, этапы — последовательностью, фильтры портфолио — вкладками-кнопками с состоянием выбора. Сохранены все якоря, диалоги, подготовка заявки, копирование и ручной резервный сценарий. Добавлены ссылка перехода к содержимому, подписи диалогов, видимый фокус, закрытие мобильного меню клавишей Escape и проверка полей.

Первый экран переработан в архитектурную обложку с широким кадром. Убрано дублирование контактного действия в шапке, уплотнены преимущества, уточнены подписи портфолио, этапы работы собраны в последовательность. Диалог показывает выбранное изображение. Ограничение отправки заявки объясняется перед полями.

Проверка выполнена в реальном Chromium через Playwright MCP: desktop 1440 px, tablet 768 px, mobile 390 px с touch-контекстом, отсутствие переполнения на восьми ширинах от 320 до 1920 px. Из-за недоступности HTTP-сервера использовался перехват запроса с точным HTML из dist/index.html. Новые зависимости не добавлены.

## Фоновая анимация строительства

Декоративная Canvas-анимация занимает фон всего первого блока. Единственные видимые элементы управления — круглая кнопка включения/выключения и тонкий ползунок без подписей. У элементов сохранены доступные названия для скринридеров и управление клавиатурой.

Воспроизведение занимает 7 секунд (вчетверо быстрее исходной версии) и останавливается на последнем кадре; повторное включение начинает его заново. Перемотка работает в обе стороны. Вне экрана и в скрытой вкладке анимация приостанавливается. При reduced motion автоматически показан последний кадр. Без JavaScript остаётся приглушённая исходная фотография.

Новых библиотек и внешних запросов нет. `scripts/sync-inline.py` объединяет `script.js`, `construction.js` и `text-build.js` в один встроенный скрипт, сохраняя автономность HTML.

## Экран загрузки

При открытии страницы логотип КРЕСТАВР прорисовывается на светлом фоне. Скрипт `loader.js` встроен в head и запускается до разбора крупных изображений. После window.load он ждёт шрифт и декодирование изображений, затем даёт браузеру подготовить первый кадр и плавно открывает страницу. Строительство запускается после исчезновения загрузочного экрана.

Без JavaScript экран не показывается и не блокирует сайт. При уменьшении движения логотип статичен. Ошибки изображений обрабатываются, а защитный таймер через 20 секунд снимает блокировку при зависших ресурсах. Никаких искусственных минимальных задержек нет.

Анимация строительства работает только у главного заголовка «01 — Компания». Каждая арматурная буква собрана из изогнутых ребристых SVG-прутьев по её осевым линиям. Два рабочих плавно переходят между участками и останавливаются для работы: устанавливают прутья, наклоняют вёдра и заливают бетон, затем наносят краску валиком. Появление материала привязано к месту и времени работы инструмента. Рабочие прыгают по четырём углам вокруг заголовка, следуя внешнему периметру и не заходя на буквы. Рабочие меняют угол только при смене материала — два прыжка за всю сцену у каждого, остальное время работают на месте. Траектории включают дугу и короткое приседание при приземлении; рабочие начинают с противоположных углов и поворачиваются к тексту. Размер моделей подстраивается под свободное место на мобильном экране. Вся сцена ускорена вдвое: перемещения занимают 200 и 150 мс, инструменты и смена материалов синхронно ускорены.

Эффект запускается один раз при появлении заголовка. Все модели и материалы встроены локально. Исходные текстовые узлы остаются доступными и восстанавливаются после анимации, при ошибке, смене размера или уходе со страницы. Смена этапов использует Web Animations API без цикла requestAnimationFrame; независимый таймер гарантирует раскрытие текста даже при остановке анимаций. Без JavaScript и при `prefers-reduced-motion` весь текст показывается сразу.

Фон «02 — Услуги» при первом появлении проходит стадии прорисовки архитектурного плана, тонированного рисунка и заливки исходным цветом секции. Локальный SVG находится под контентом, не принимает события и удаляется по завершении или при ошибке. Без JavaScript и при уменьшении движения остаётся исходный однотонный фон. Исходник `dist/services-blueprint.js` также синхронизируется в HTML.
